# Vereniging van Eigenaren (VvE) Contactmanager

Deze applicatie wordt geïmplementeerd in **Fase 3** van het project.
Zij zal gericht zijn op:
- Eigenaren van woningen
- Bedrijven / commerciële plintruimtes
- Garagehouders / parkeerplaats-eigenaren
- Breukdelen / stemverhoudingen en eigenaren-specifieke noodcontacten
